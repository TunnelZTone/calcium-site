Updates

Release notes for CalcIUM on Android. Newest first.

Version 1.0.6

September 8, 2026

  • Added four new PRO themes: Moonstone Slate, Retro Instrument, Cathedral Obsidian and Sanctum Sky.
  • All 10 themes have been further refined with individual fonts, button shapes, colors, shadows and status-bar styling.
  • Added display textures for all 10 themes. They are enabled by default and can be turned off in Settings -> View Options -> Screen texture.
  • Improved expression scaling: large text now stays large longer and only shrinks or wraps when needed.
  • Improved handling of long expressions and different screen sizes.
  • Additional visual polish, optimizations and stability improvements.

Version 1.0.5

September 2, 2026

  • Added two new PRO themes: Nordic Blue and Violet Carbon.
  • Improved Time / DateTime tools.
  • Now uses your local time zone.
  • Added calendar and time pickers for DateTime input.
  • Improved DateTime formatting, validation and responsive text scaling.
  • Fixed several UI and theme-related issues.
  • General bug fixes and stability improvements.

Version 1.0.4

August 20, 2026

  • Added two new PRO themes: Industrial Ember and Porcelain Wine.
  • Added Portuguese (Brazil), Hindi, and Japanese.
  • The Extension Panel is now available directly from the main menu.
  • Improved CalcIUM PRO information and access, including clearer feature details and premium themes in the Theme Picker.
  • Improved UI tips and error messages, plus bug fixes and stability improvements.

Version 1.0.3

August 10, 2026

  • Added an optional Google Play rating reminder for free users.
  • Improved the app rating flow.
  • Updated compatibility for newer Android versions.
  • Minor fixes and stability improvements.

Version 1.0.2

April 8, 2026

Improvements to in-app hints, the About screen, and the rate-app flow.

  • Hints and info lines: clearer priority so input hints show when they matter most.
  • Hints and info lines: language-aware labels and adaptive font sizing for better readability in tight layouts.
  • Hints and info lines: consistent text overflow behavior across hint and info fields.
  • About: link to the official website; refined contact layout with icons.
  • Rate app: updated Google Play link (including reviews context).

Version 1.0.1

Earlier release

Maintenance and polish after the initial public release. For full store-facing details, see the app listing on Google Play.
